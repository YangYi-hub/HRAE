# HRAE Supplementary Materials

This repository contains videos of real-world manipulation experiments for HRAE, GR00t-N1.7, and π0. The videos primarily showcase failure cases discussed in the paper to analyze failure modes. Some successful examples are also provided for each method.

Videos are organized by method under `Supplementary_Materials/Real_world_manipulation_records/`, with `failed_cases/` and `success_cases/` folders.
